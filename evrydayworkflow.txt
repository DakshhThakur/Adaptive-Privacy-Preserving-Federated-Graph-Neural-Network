Days 1–7: Data → Graph
Day	What we will do	Output


1	Set up project folders, Python environment, and verify dataset	Working environment
2	Load UNSW-NB15, inspect columns, missing values, labels, and class distribution	EDA results
3	Clean data, encode categorical features, scale numerical features, and save processed data	data/processed/
4	Understand graph construction: nodes, edges, and features	Graph design
5	Construct a network graph from available network relationships	graph_data.pt
6	Visualize the graph and inspect nodes, edges, and features	Graph visualization
7	Build a basic GNN using the constructed graph	First GNN model


Days 8–14: GNN → Federated Learning
Day	What we will do	Output
8	Train the GNN and evaluate anomaly detection	Accuracy, precision, recall, F1
9	Improve the GNN and handle class imbalance	Better baseline
10	Understand and implement graph-based train/validation/test splitting	Reliable evaluation
11	Simulate 3 distributed clients from the dataset	Client datasets
12	Train one local GNN on each client	3 local models
13	Implement Federated Averaging (FedAvg)	Global model
14	Evaluate the federated model against the centralized GNN	Comparison results


Days 15–21: Privacy → Adaptive Aggregation
Day	What we will do	Output
15	Understand privacy risks in federated learning	Privacy design
16	Implement gradient clipping	Clipped updates
17	Add Gaussian noise for differential privacy	Private local updates
18	Test privacy parameters and observe their effect on performance	Privacy experiment
19	Design adaptive client weighting	Adaptive aggregation logic
20	Implement adaptive aggregation	Adaptive global model
21	Compare FedAvg, privacy-preserving FL, and adaptive FL	Main experiment

Day	What we will do	Output

28	Organize GitHub repository and write README	Complete project

30	Final testing, screenshots, presentation, and paper polishing	Final submission
